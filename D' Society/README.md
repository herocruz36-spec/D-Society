# D' Society Website

A responsive single-page website inspired by the supplied reference image.

## Files
- `index.html` — page structure
- `style.css` — responsive design, glass effects and animations
- `script.js` — typing dots, navigation popup, mobile menu and Google Form redirect
- `Screenshot 2026-09-29 025025.png` — supplied reference image used as the visual background

## Google Form
Open `script.js` and replace:

const GOOGLE_FORM_URL = "https://forms.google.com/";

with your actual Google Form URL.

## Run
Keep all files in the same folder and double-click `index.html`.

For a local server:
- VS Code + Live Server, or
- `python -m http.server`
